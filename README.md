## 🚀 Featured Project

### 🗼 AI Agent Control Tower (ACT)

**AI Agent Control Tower** is an independent enterprise AI infrastructure project exploring the control mechanisms organizations need as AI agents gain access to identities, credentials, APIs, tools, MCP servers, data platforms, cloud resources, and other agents.

The project investigates questions such as:

- What AI agents exist across an organization?
- Who owns them?
- What identities and credentials are they operating with?
- Which tools, APIs, MCP servers, applications, and resources can they reach?
- How does authority propagate between humans, agents, identities, credentials, tools, and resources?
- What is the potential blast radius of an agent?
- What evidence exists for an agent's actions and authority?
- What can an organization observe?
- What can it actually govern or control?

> **Visibility is not the same as control.**

## 🧭 Engineering Principles

A few principles guide how I approach enterprise AI systems:

> **Visibility is not the same as control.**

> **Authority should be explicit, bounded, and auditable.**

> **AI agents should receive governed capabilities rather than unrestricted infrastructure access.**

> **Security controls should describe what they can actually enforce — not what they merely observe.**

> **Enterprise AI systems should be observable, auditable, secure, and governable by design.**
